# Keyring Studio

나만의 이야기를 담은 아크릴 키링 쇼핑 앱 (모바일 웹).

귀여운 캐릭터 키링을 탐색하고, 옵션을 골라 장바구니에 담고, 위시리스트로 관리하는 커머스 앱 컨셉 구현입니다.
상품 일러스트는 이미지 에셋 없이 전부 인라인 SVG로 그려집니다.

## 화면

- **온보딩** — 3장 슬라이드, 첫 방문 시 1회 노출
- **홈** — 히어로 배너 캐러셀 · 카테고리 · 인기 상품 그리드
- **상품 상세** — 이미지 영역 · 키링 타입/수량 옵션 · 장바구니 담기/바로 구매
- **카테고리** — 필터 칩 + 상품 그리드
- **위시리스트 / 장바구니 / 마이페이지**

장바구니·위시리스트 상태는 `localStorage`에 영속화됩니다.

## 기술 스택

React 18 · TypeScript · Vite 5 · react-router-dom v6 · CSS(디자인 토큰)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 프로덕션 빌드
```
